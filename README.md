# Dron Yarışı

Tarayıcıda çalışan 3D low-poly arcade dron yarış oyunu (Three.js, tek dosya).

- `index.html` – oyunun güncel sürümü (internet gerekir: Three.js ve online mod için PeerJS CDN'den yüklenir)
- `Dron-Yarisi-offline.html` – internetsiz çalışan sürüm

Özellikler: 8 dron, 8 pist (tünel, yokuş, dağ), 3 tur, online çoklu oyuncu, telefonda dokunma ve eğme ile kontrol, arka plan müziği.
